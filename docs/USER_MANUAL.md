# 📖 User Manual

## 1. Staff Manual

### 1.1 Attendance Check-in / Check-out
1. Open attendance page
2. Click **Check-In**
3. System confirms successful check-in
4. At the end of shift, click **Check-Out**

---

### 1.2 Staff Login
1. Open login page
2. Enter username and password
3. If checked-in, system grants dashboard access
4. If not checked-in, system denies login

---

### 1.3 POS Transaction (Cashier)
1. Login as cashier
2. Create new order (dine-in / take-away)
3. Add menu items into cart
4. Checkout order
5. Confirm payment method
6. Generate receipt/invoice

---

### 1.4 Booking Approval (Cashier)
1. Open booking list
2. View booking details
3. Approve or reject booking request
4. Booking status will be updated

---

### 1.5 Inventory Management (Manager/Admin)
1. Open inventory module
2. Add ingredients
3. Update stock in/out
4. Monitor low stock alerts

---

### 1.6 Recipe Management (Manager/Admin)
1. Open recipe module
2. Select a menu product
3. Add ingredient list and quantity
4. Save recipe configuration

---

## 2. Customer Manual (QR Ordering)

### 2.1 Access Menu
1. Scan QR code
2. Browse menu items
3. Filter by category or tags

---

### 2.2 Add to Cart / Buy Now
1. Select a menu item
2. Click **Add to Cart** or **Buy Now**

---

### 2.3 Checkout
1. Open cart
2. Click checkout
3. Choose:
   - Dine Now
   - Booking
4. Fill customer information:
   - name
   - phone number
   - seat/table
   - number of people
5. If booking selected, input booking time

---

### 2.4 Payment
1. Choose payment method
2. Complete payment using Midtrans simulation
3. If payment success → order is confirmed
4. If payment canceled/failed → order is not stored
